# Place XP Landing Page Implementation

You have been provided with the following project assets:

- **prd.md** → Complete Product Requirements Document for the landing page.
- **components.md** → Collection of ReactBits components that should be used throughout the UI.
- **colour.md** → Official design system including brand colors, typography, spacing, gradients, shadows, button styles, and theme guidelines.
- **logo.png** → Official Place XP club logo.

Your first task is to carefully read and understand **all four files before writing any code.**

Treat these files as the single source of truth.

---

## Goal

Build a **production-quality landing page** for **Place XP**, the official placement-focused technical club of VIT Chennai.

This is **not** a generic college club website.

The experience should feel like a premium global developer community similar in quality to:

- GitHub Education
- GitHub Campus Experts
- Linear
- Vercel
- Stripe

Do **not** copy these websites. Instead, take inspiration from their design philosophy:

- Premium
- Minimal
- Modern
- Community-first
- Elegant
- Highly polished
- Smooth interactions
- Exceptional typography
- Plenty of whitespace

The website should feel like a startup product rather than a university website.

# Color System

Use only the colors defined inside **colour.md**.

Do not invent random colors.

Maintain a consistent design system throughout the application.

Orange should be reserved for:

- Primary CTAs
- Highlights
- Active states
- Important statistics

Blue should represent the brand.

The overall UI should remain dark and premium.
